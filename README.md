# X1EmuX68

X1 Emulator for X68000

## これはなに？

シャープの8ビットパソコン「X1」を、X68000の上で動かすエミュレータです。

X1EmuX68は、森田 浩次氏の「Ｘ１エミュレータ for X68000 version 1.00」（1993年）を、GORRYが改造したものです。1995年のrelease 1・2、1999年のrelease 3に続いて、2026年より新たな改修を行っています。

## 動作環境

- X68000（実機またはエミュレータ）
- Human68k
- 31kHzまたは24kHzの画面表示

## 準備（ROMファイル）

X1のROMファイルを、`X1.x` と同じフォルダに置きます。ROMファイルは同梱していません。お手持ちのX1実機から吸い出してください。作成方法は `doc/X1.DOC` および `doc/X1VG.DOC` をご覧ください。

| ファイル | 内容 | ファイルがないときの動作 |
|---|---|---|
| `IPLROM.X1` | X1のIPL-ROM（4096バイト） | `IPLROM.X1T` を読み込みます |
| `IPLROM.X1T` | X1turboのIPL-ROM（32768バイト） | `FD0` のディスクイメージから起動プログラムを読み込みます |
| `CGROM.X1` | X1のCG-ROM（8×8ドット、2048バイト） | X68000のフォントで代用します |

`X1.x` とROMファイルをPATHの通ったフォルダに置き、ディスクイメージとCONFIGファイルをソフトごとのフォルダにまとめておく、という形で整理できます。

## 使い方

Human68kのコマンドラインから `X1.x`（または `X1DB.x`）を実行します。

```
X1 [-F CONFIGファイル] [-D FDn=ディスクイメージ] [-H]
```

| オプション | 内容 |
|---|---|
| `-F ファイル名` | CONFIGファイルを指定します。拡張子を省略すると `.X1` を補います。指定しない場合は、カレントフォルダの `CONFIG.X1` を読み込みます |
| `-D FDn=ファイル名` | `-D FD0=B:\DATA.D88` のように、ドライブ0～3のディスクイメージを直接指定します。CONFIGファイルの指定より優先します |
| `-H` | 24kHzの画面で起動します。指定しない場合は31kHzです。CONFIGファイルの `DISPLAY=` より優先します |

### キー操作

| キー | 動作 |
|---|---|
| `CTRL` + `OPT.1` | IPLリセット |
| `CTRL` + `OPT.2` | NMIリセット |
| `OPT.2` + `OPT.1` | エミュレータの終了 |
| `OPT.2` + テンキー `0`～`3` | 対応するドライブのディスクイメージを次のものに入れ替える |

## 主な改修点

2026年の改修で、次の機能を追加しました。

- **D88形式のディスクイメージ対応**: 従来の2D形式（256バイト/16セクタ/両面80トラックのベタイメージ）に加えて、D88形式を読み書きできます。128/256/512/1024バイトのセクタやフォーマットにも対応しています。
- **複数枚ディスクイメージの入れ替え**: 1ドライブにつき最大10枚のイメージを登録し、実行中にキー操作で入れ替えられます。
- **ステータス行**: 画面上部に、各ドライブのディスクイメージ名とアクセスランプを表示します。
- **FM音源とPSGの同時演奏**: FM音源の1～4chとPSGを同時に鳴らせます。
- **ROM・ディスクイメージの配置整理**: ROMファイルは実行ファイルと同じフォルダから、CONFIGファイル内のディスクイメージ等はCONFIGファイルのあるフォルダから読み込みます。
- **起動時のディスクイメージ確認**: 開けないディスクイメージがある場合は、起動前に通知します。

### CONFIGファイル

テキストファイルで、1行に1つずつ `項目=値` の形式で記述します。全体の例は `CONFIG.X1.sample` を参照してください。

```
FD0=DISK1.D88
FD1=DISK2.D88
FD10=DISK3.D88
OPM=MIX
STATUS=ON
```

2026年の改修で追加・変更した項目は次のとおりです。そのほかの項目については `doc/X1.DOC` および `doc/X1VG.DOC` をご覧ください。

| 項目 | 値 | 初期値 | 内容 |
|---|---|---|---|
| `FD0`～`FD3` | ファイル名 | なし | 起動時にドライブ0～3へセットするディスクイメージ。2D形式とD88形式は中身から自動判定します。 |
| `FD10`～`FD93` | ファイル名 | なし | 入れ替え用のディスクイメージ。`FDxy` の `x`（1～9）が順番、`y`（0～3）がドライブ番号です。 |
| `OPM` | `ON` / `OFF` / `MIX` | `OFF` | FM音源をエミュレートするか。`MIX` を指定するとFM音源の1～4chのみを演奏します。`PSG=ON`と共に指定することで、FM音源（1～4ch）とPSGを同時演奏します。 |
| `STATUS` | `ON` / `OFF` | `ON` | ONで画面上部のディスクステータス行を表示します。 |

#### ディスクイメージの入れ替え

`OPT.2` を押しながらテンキーの `0`～`3` を押すと、そのドライブのイメージが `FD0` → `FD10` → `FD20` → … → `FD90` → `FD0` の順に切り替わります（ドライブ0の場合）。指定のない番号はスキップします。

### ファイル名の相対パス解決

CONFIGファイルの中に相対パスで記述したファイル名は、そのCONFIGファイルのあるフォルダを基準に探します。`-D` オプションで指定したファイル名は、カレントフォルダを基準に探します。

### 修正した不具合

- リセット後、PSGの音色が設定されないままになる不具合を修正しました。
- 起動時にファイルをすべて閉じたあと、閉じたファイルの番号をディスク処理が保持したままになっていた不具合を修正しました。

### 既知の制限事項

- 複数枚のイメージを連結したD88ファイルは、1枚目のみ使用します。
- ステータス行では、2バイト文字を含むファイル名は正しく表示されません。

## ソースからのビルド

### X68000上でのビルド

X68000（実機またはエミュレータ）上で `make` を実行すると、`X1.x` と `X1DB.x` が生成されます。アセンブラは `HAS.X`、リンカは `HLK.X` を使用します。

### Windows環境でのビルド・テスト

PythonがインストールされているWindows環境では、次のコマンドで `X1.x` と `X1DB.x` をビルドできます（X68000上でビルドしたものと同一のバイナリが生成されます）。

```
python test/run.py build
```

テストのみを実行する場合は `python test/run.py` を実行します。

ビルドおよびテストには、以下のツールが必要です。`../../tools/` はリポジトリのフォルダから2つ上の `tools` フォルダを指します。環境変数 `X1TEST_TOOLS` で場所を変更できます。

- `../../tools/run68x/run68.exe`（[run68x](https://github.com/kg68k/run68x) をビルドしたもの）
- `../../tools/has309/HAS.X`
- `../../tools/HLK301B/hlk301.x`
- `../../tools/macros/DOSCALL.MAC`
- `../../tools/macros/IOCSCALL.MAC`

注意:

- ビルドを実行すると、リポジトリ直下の `X1.x`・`X1DB.x` および `obj/` 内のファイルが上書きされます。
- リポジトリのパスが長いと、`HAS.X` が出力ファイルを開けない場合があります。その場合は環境変数 `X1TEST_WORK` で短いパスの作業フォルダを指定してください。
