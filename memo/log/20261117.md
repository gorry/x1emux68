## D88形式のディスクイメージへの対応

- ユーザーの指示：ゴールは「ディスクイメージファイルとしてD88形式を使用できるようにする」。D88形式は https://github.com/gorry/d88toolg を参照
- 調べたこと
  - D88形式：`d88toolg` の `spec_d88.md`。ヘッダは688バイト（テーブルを160個に切り詰めた672バイトのものもある）。トラックごとにセクタヘッダ16バイト＋データが並ぶ
  - 今のＦＤＣ（`X1IO.has`）：ファイル内の位置を `TRACK`（シリンダ*`$2000`）＋`HEAD`＋`SECTOR` で計算し、`B_DISK` に読んでから `$0FFB` で1バイトずつ渡す。ファイルはモーターONで開き、OFFで閉じる
  - IPL ROM がないときの起動（`X1EMU.has` の `FC_02`）も `FD0` のファイルを直接読んでいる
  - `X1IO.has` の変数は `A_MEM` からの16ビット相対、Z80の表は `A_BAS` からの16ビット相対で読まれている。コードやデータを足す場所に制約がある（`design.md` に書いた）
- 決めたこと（ユーザーには未確認。`design.md`・`spec.md` に書いた）
  - 形式は中身で判定する。拡張子は見ない
  - 2D形式の処理は残し、D88の処理は `src/X1D88.has` に分ける
  - セクタは C と R で探す。セクタの大きさ・個数・並びはイメージのとおりに扱う
  - ライトトラックは今あるセクタを `$FF` で埋めるだけ。構成は変えない
  - 複数枚のイメージは1枚目だけ使う
- 作ったもの・直したこと
  - `src/X1D88.has`（新規）：`D88INIT`・`D88OPEN`・`D88RD`・`D88RA`・`D88WC`・`D88WR`・`D88CHK`・`D88RREC`
  - `src/X1IO.has`
    - `INITIO`：`D88INIT` を呼ぶ。`_ALLCLOSE` のあと `FILENO` を `$FFFF` に戻すようにした（閉じたハンドルが残っていた）
    - `FOPEN`：開いたあと `D88OPEN` を呼ぶ。ヘッダが書き込み禁止ならステータスに反映
    - `RDATA`・`READADRS`・`WDATA`・`OTESCT`：D88用ルーチンを呼び、処理済みなら戻る
    - `E_RDST` を追加。`INESCT`（リードの終了）のステータスと、`RTIFF8` のダミーリード省略の判定を、バイト数ではなく `E_RDST` で決めるようにした

## CONFIGの「OPM=MIX」の追加

- ユーザーの指示
  - ＰＳＧのエミュレーションで OPM のどのチャンネルを使っているか調べる
  - CONFIG に「OPM=MIX」を追加する。OPM エミュレーション側の ch5-8 をマスクし、「ch1-4 はＦＭ、ch5-8 はＰＳＧ」として使えるようにする
- 調べたこと
  - ＰＳＧは OPM の ch5～ch8（レジスタ上の番号は 4～7）を使う。トーンA・B・C が ch5・6・7（`PSG00`～`PSG05`・`PSG08`～`PSG10`）、ノイズが ch8（`PSGVOI` の `$20+7`、音量は `$7F`、周波数は `$0F`）
  - `OPM=ON` のときは、ＦＭ音源の書き込みがそのまま ch5～ch8 にも届く。`$24`～`$27` への書き込みだけ `F_PSG` に印を付け、あとでＰＳＧの音色を入れ直している
- 決めたこと（ユーザーには未確認。`spec.md` に書いた）
  - `F_OPMSW` の値は `$FF`=ON、`$01`=MIX。OFF かどうかの判定（0 かどうか）は今のまま使える
  - `MIX` で捨てるのは、キーオン（`$08`）の ch5～8、ノイズ（`$0F`）、`$20`～`$FF` の ch5～8。タイマーや LFO などチャンネルに属さないレジスタは通す
  - `MIX` は `PSG` の指定を変えない
- 作ったもの・直したこと
  - `src/X1EMU.has`：`CNFOPM` が `MIX` を読む。`CHRMIX` を追加
  - `src/X1IO.has`：`OPMDAT` で `F_OPMSW` を見て、`MIX` なら `OPMMIX` へ分岐。`OPMMIX` を追加
  - `src/X1IO.has`：`INITFM` の最後で `F_PSG` を `$FFFFFFFF` に戻すようにした。`INITFM` は `$20`～`$FF` を全部 `$FF` で埋めるので、リセットのあとＰＳＧの音色が入らないままになっていた。`MIX` ではＦＭ音源側から印が付くこともないので直した
  - `memo/doc/spec.md`：「音源」の節を追加
  - `X1.x`・`X1DB.x`・`obj/*.o` を、変更後のソースからビルドしたものに置き換えた
- 確かめたこと
  - `run68x` の上で HAS・HLK がエラーなく通ること
  - リンクマップで、`A_BAS` から `T_ROM` の終わりまでが16ビットに収まること（`X1DB.x` で `$73F6`）
